Техническое задание на проект: Travel Budget

1. Цель проекта

Разработка веб-сервиса для планирования бюджета и учета расходов во время путешествий.
Проблема, которую решает сайт: сложность контроля финансов в поездках, когда траты происходят в разных валютах, а бюджет ограничен в рублях.
Сервис помогает пользователям:

Планировать общий бюджет поездки.

Вносить расходы в любой валюте с автоматической конвертацией.

Видеть реальный остаток средств и анализировать структуру трат, чтобы не выйти за рамки бюджета.

2. Роли пользователей

Гость: Посетитель, который может просматривать приветственную страницу (Landing page) с описанием возможностей сервиса, а также имеет возможность зарегистрироваться или войти.

Авторизованный пользователь: Основной пользователь. Имеет доступ к личному кабинету, может создавать путешествия, добавлять/редактировать расходы, просматривать статистику и графики. Доступ к данным других пользователей закрыт.

Администратор: Суперпользователь, имеющий доступ к Django Admin. Управляет справочником валют и может принудительно обновлять курсы валют.

3. Модели данных

Модель 1: Trip (Путешествие)
Основная сущность, объединяющая расходы.

Поля: user (Владелец), name (Название поездки), budget (Лимит бюджета в рублях), start_date (Дата начала), end_date (Дата окончания).

Модель 2: Expense (Расход)
Запись о конкретной трате денежных средств.

Поля: trip (Связь с путешествием), title (Описание), amount (Сумма в валюте), currency (Связь с валютой), category (Категория: Еда, Жилье, Транспорт и т.д.), date (Дата траты).

Логика: Содержит свойство для динамического пересчета суммы в рубли (amount_in_rub).

Модель 3: Currency (Валюта)
Справочник для хранения кодов и актуальных курсов валют.

Поля: code (ISO код: USD, EUR), name (Название), rate_to_rub (Курс обмена к рублю).

4. Ключевой функционал

Создание поездки: Пользователь создает карточку путешествия (например, "Тайланд 2024"), устанавливая даты и плановый бюджет в рублях.

Мультивалютный учет: При добавлении расхода пользователь выбирает валюту (например, USD). Система автоматически конвертирует сумму в рубли по текущему курсу и вычитает её из общего бюджета поездки.

Визуализация данных (Matplotlib): На странице детального просмотра поездки формируется и отображается диаграмма распределения расходов по категориям, сгенерированная на сервере с помощью библиотеки Matplotlib.

5. Внешние интеграции / Аналитика

Внешнее API: Интеграция с exchangerate-api.com (через библиотеку requests) для получения актуальных курсов валют и обновления их в базе данных.

Библиотека Matplotlib: Использование Python-библиотеки matplotlib на бэкенде для генерации статических графиков (Pie Chart) в формате изображений (PNG/Base64), отображающих долю затрат каждой категории.

Chart.js: Дополнительно используется JS-библиотека на фронтенде для интерактивного отображения динамики расходов по дням.
